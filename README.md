# КругоЗор

КругоЗор показывает изображение с веб-камеры в плавающем окне поверх рабочего стола и передаёт его в виртуальную камеру для Телемоста, Zoom, Teams и OBS. Окно можно скрыть, сохранив видео в звонке.

## Быстрый запуск

- [КругоЗор Lite для Windows x64](https://github.com/Akudlay-ru/KrugoZor/releases/tag/v15.0-lite) содержит обе модели MediaPipe и запускается без установки Python. Размер файла около 115 МиБ.
- Загрузчик Lite занимает около 72 КиБ. Его можно собрать из репозитория командой `build.bat launcher`. При первом запуске он скачивает пакет из GitHub Releases, сверяет размер и SHA‑256 и сохраняет его в `%LOCALAPPDATA%\KrugoZor\Lite`. Следующие запуски используют проверенный локальный файл.

Для виртуальной камеры нужен установленный совместимый драйвер, например OBS Virtual Camera. Само видео обрабатывается на компьютере.

## Возможности

- Круглое или квадратное плавающее окно, в том числе поверх других окон.
- Динамический кроп по лицу и три редактируемых пресета во вкладке «Кроп».
- Обычный хромакей по цвету, динамические пипетки и гибридный режим с сегментацией MediaPipe.
- Режим «Как в Телемост» с белым фоном, портретным градиентом или своим изображением. Размер круга и масштаб портрета регулируются отдельно.
- Ручной PTZ и опциональный авто-PTZ, если камера и драйвер поддерживают поворот, наклон и зум. Программный кроп и хромакей работают с обычной веб-камерой.
- Контекстное меню, системный трей и горячие клавиши.

## Запуск из исходников

Проверенная конфигурация: Windows x64 и Python 3.14. В корне клона выполните:

```bat
py -m pip install -r requirements.txt -r requirements-optional.txt
py fetch_models.py
py KruGoZor.pyw
```

Скрипт загружает обе модели с официального сервера Google, проверяет SHA‑256 и сохраняет файлы рядом с программой. Подлинные файлы повторно не скачиваются. [Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker) · [Image Segmenter](https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter)

Пользовательские настройки записываются рядом с запущенной программой в `KrugoZor_data\config.json`. При работе с OpenCV 5 для автослежения нужен MediaPipe. Поддержка Haar зависит от сборки OpenCV.

## Сборка

Для полной и лёгкой сборок заранее установите зависимости, загрузите модели и установите PyInstaller. В проверенной сборке использовался PyInstaller 6.22.3.

```bat
py -m pip install PyInstaller==6.22.3
build.bat
build.bat lite
build.bat launcher
```

| Команда | Результат |
|---|---|
| `build.bat` | `dist\KruGoZor.exe`, полная автономная сборка |
| `build.bat lite` | `dist\KruGoZor-lite.exe`, автономная сборка без отдельного FFmpeg-бэкенда OpenCV и лишних зависимостей |
| `build.bat launcher` | `dist\KruGoZor-lite-launcher.exe`, загрузчик на системном .NET Framework Windows для пакета `v15.0-lite` |

Скрипт сборки пользуется установленными пакетами и не удаляет каталог с предыдущими сборками. Для проверки моделей на локальном портрете без захвата камеры запустите:

```bat
dist\KruGoZor-lite.exe --check-models "C:\путь\портрет.jpg"
```

Результат будет в `dist\KrugoZor_data\Logs\krugozor.log`.

## Основные файлы

| Файл | Назначение |
|---|---|
| `KruGoZor.pyw` | Интерфейс, захват, обработка и виртуальная камера |
| `kgz_face_director.py` | Поиск лица и динамический кроп |
| `kgz_hybrid_chroma.py` | Сегментация и гибридная маска |
| `fetch_models.py` | Загрузка и проверка двух моделей |
| `KruGoZor-lite.spec` | Состав облегчённой сборки PyInstaller |
| `LiteLauncher.cs` | Исходный код загрузчика |
| `style.qss` | Тема интерфейса |
